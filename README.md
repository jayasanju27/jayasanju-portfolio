# Jaya Sanju 3D Personal Portfolio

React + Vite + Tailwind CSS portfolio based on the provided portfolio source.

## Run

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Build

```bash
npm run build
```

The 3D background loads Three.js from CDN as used by the original source.
